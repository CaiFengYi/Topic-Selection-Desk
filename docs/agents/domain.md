# Domain Docs

本项目采用 single-context，使用统一的领域词汇表。

## 探索前读取

1. 根目录 `PROJECT_CONTEXT.md`：了解项目进展、已确认决定与待实现事项。
2. 根目录 `CONTEXT.md`：理解领域术语。
3. `docs/adr/`：读取与当前工作相关的架构决策。

文件或目录缺失时静默继续，不预先要求创建。
`grill-with-docs` 等文档生产技能在术语或决策明确后按需创建。

## 文档职责

- `CONTEXT.md`：领域术语及含义。
- `PROJECT_CONTEXT.md`：项目进展与决策记录。
- `docs/adr/`：按需产生的架构决策记录。

## 使用统一术语

任务标题、重构建议、诊断假设和测试名称中的领域概念，
应采用 `CONTEXT.md` 中的定义，避免使用其中明确排除的同义表达。

需要的概念尚未收录时，先判断是否引入了不必要的新术语；
确有缺口则记录，供 `grill-with-docs` 后续澄清。

## 显式指出决策冲突

方案与现有 ADR 冲突时，明确指出相关 ADR 及重新讨论的理由，
不得默默覆盖原决定。
